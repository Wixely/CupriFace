3D

An ISurfaceSource is a live picture the engine composites like any other content. A video is one; so is a 3D viewport. CupriFace ships no 3D renderer and knows nothing about GL — the model below is drawn by sample code (samples/Demo3d, in no shipped package). The engine's part is deciding how those pixels reach the frame.

Drawn by — {{Gpu3d}}

What is actually being shown

A glTF 2.0 model (teapot.glb, 4,032 triangles, one base-colour texture) drawn with a small Cook-Torrance PBR shader. The renderer is a sample, not part of the engine — CupriFace does not ship 3D, and nothing here required changing it.

This host has not wired a 3D surface, so the viewport paints nothing and the panel behind it shows through. That is the engine's ordinary behaviour for a surface with no frames — the same fallback that shows a <cupri-video>'s poster — and the page did not have to handle the case.

The panels overlapping the viewport are plain elements at three different alphas. They composite correctly over the 3D on both lanes, which is the part that is hard: on the web the viewport is a real <canvas> underneath the page, kept glued to this box — through the scroll offset, the clip against every overflow ancestor, and any transform on the chain.

Scroll this page and the viewport stays in its box on every host.

Keyboard

Everything on this page is reachable without a pointer. Tab and Shift+Tab walk the controls below — the focus ring shows where you are — and Enter or Space activates whatever holds focus.

First Notify Monthly Yearly Last

The composer below is marked submit-on-enter: Enter sends, Shift+Enter starts a new line, and Ctrl+Enter sends from anywhere — including while a different field has focus. On a phone the on-screen keyboard shows a Send key, because the same attribute sets the enter-key hint.

{{.}}
Last key{{KeyLog}}
Sent{{SentLabel}}

Type @ followed by a letter or two in the composer — a name list opens. ↓ and ↑ move the highlight while the composer still has focus, Enter inserts the name and leaves the caret after it so you can keep typing, and Escape closes the list. Each of those was impossible before v0.17.0.

Ctrl+K opens the command palette, Ctrl+Enter sends, Escape clears the composer. Try Escape with the palette open: it closes the palette first and clears nothing, because the engine's own dismissals outrank an app's binding — then a second Escape reaches this page.
