# Lottie demo

`cupri-spinner.json` is **original work, MIT-licensed with this repository** — hand-authored here
rather than downloaded, so its licence is not something to take on trust from a third-party gallery.
It is a plain Lottie file (schema 5.7.4): two ellipse layers, a rotation and a trim-path, in
CupriFace's own copper. Any Lottie player renders it.
